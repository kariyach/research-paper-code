# Code and Data

This repository contains the R code, datasets, dictionaries, and Quarto files used in my research projects.

Each project folder contains the source files used to generate the analyses, figures, and tables presented in the corresponding study.

To respect copyright restrictions, the datasets included here are illustrative samples rather than the original research data. Likewise, the code is provided as a reference for the analytical workflow and visualization techniques, and is not intended to be a complete reproduction of every step of the original analysis.

For more information about my research projects, publications, and presentations, please visit my [academic website](https://kariyach.github.io).
